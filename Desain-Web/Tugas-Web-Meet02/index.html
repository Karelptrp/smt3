Penjelasan & Analisis Mandiri

1. Pemahaman Fungsi Tag:

Tag <h1> sampai <h3> berfungsi untuk heading dimana kita bisa menandai judul atau subjudul pada halaman web. Tag <p> digunakan untuk membuat paragraf teks, sedangkan tag <img> digunakan untuk menampilkan gambar. Tag <a> berfungsi untuk membuat tautan ke halaman lain atau sumber eksternal. Tag <ul> dan <ol> digunakan untuk membuat daftar atau list dimana ul adalah unordered list dan ol adalah ordered list, lalu <br> untuk break setiap kita habis menambahkan sesuatu atau paragraf
